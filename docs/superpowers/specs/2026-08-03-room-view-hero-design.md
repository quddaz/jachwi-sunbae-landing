# 자취선배 실사형 방 둘러보기 히어로 디자인

## 목표

기존의 밝은 2열 히어로와 로드뷰 일러스트 카드를, 실제 고시원 방문 시 문을 열고 방 안을 살펴보는 듯한 몰입형 상단 화면으로 교체한다. 첫 화면에서 서비스의 핵심 가치인 “사진에 나오지 않는 생활 조건까지 계약 전에 확인한다”를 즉시 이해시키고, 25개 체크리스트 신청으로 자연스럽게 연결한다.

## 범위

- `index.html`의 사이트 헤더와 첫 번째 히어로 섹션
- 히어로에 필요한 실사형 방 이미지 자산
- 히어로 전용 반응형 스타일과 가벼운 진입·배경 이동 애니메이션
- 히어로 CTA의 기존 `#get-checklist` 연결
- 기존 하단 콘텐츠, 신청 폼, 메일 발송 로직은 변경하지 않는다.

## 핵심 콘셉트

카메라는 고시원 방 문 앞에 서서 내부를 보는 높이와 화각을 가진다. 침대, 사용 가능한 높이의 책상과 의자, 외창, 벽면과 수납공간이 한 화면에서 식별되어야 한다. 방은 지나치게 넓거나 호텔처럼 고급스럽지 않고, 실제 계약 후보로 볼 법한 작고 정돈된 한국형 고시원이어야 한다.

이미지는 공포스럽거나 극단적으로 낡은 분위기를 피한다. 대신 저녁 직전의 자연광과 실내 조명을 함께 사용해 현실감과 긴장감을 주고, 사용자가 “여기서 무엇을 확인해야 하지?”라고 생각하도록 만든다.

## 화면 구조

### 헤더

- 히어로 위에 겹쳐지는 투명 헤더로 전환한다.
- 왼쪽에는 흰색 `자취선배` 로고를 배치한다.
- 오른쪽에는 반투명 글래스 스타일의 `무료로 받기` 버튼을 둔다.
- 스크롤 전 첫 화면에서 배경과 충분한 명도 대비를 확보한다.

### 히어로 배경

- 화면 폭 전체와 최소 화면 높이를 채우는 실사형 고시원 방 이미지를 사용한다.
- 이미지에는 12~18초 주기의 미세한 확대와 수평 이동을 적용해 정지 이미지가 아니라 천천히 방을 살펴보는 느낌을 준다.
- 왼쪽에는 진한 검정 계열 그라데이션을 적용해 텍스트 가독성을 확보한다.
- 오른쪽 방 내부는 지나치게 어둡게 덮지 않아 침대, 책상, 창문이 계속 보이게 한다.
- `prefers-reduced-motion` 환경에서는 배경 이동을 제거한다.

### 핵심 카피

- 아이브로: `고시원 계약 전 5분만`
- 제목: `사진만 믿고 계약했다가` / `한 달 내내 후회할 수 있어요`
- 설명: `벌레·소음·환기처럼 사진에 나오지 않는 것까지 직접 살아본 선배가 알려드려요.`
- 기본 CTA: `25개 체크리스트 받기`
- 보조 문구: `광고 없이 무료로 보내드려요`

카피는 왼쪽 하단에 가까운 중앙 영역에 배치하며, 최대 폭을 제한해 방 이미지의 주요 지점을 가리지 않는다. 첫 줄은 흰색으로 표시하고 손실을 명확히 설명하는 두 번째 줄에는 보라색에서 푸른색으로 이어지는 포인트 그라데이션을 적용한다.

### 방 점검 포인트

오른쪽 이미지 위에 세 개의 점검 포인트를 배치한다.

1. 창문 부근: `외창·환기`
2. 책상 부근: `책상 높이`
3. 벽 또는 침대 헤드 부근: `벽 재질·방음`

각 포인트는 작은 원형 핀과 반투명 라벨로 구성한다. 핀은 순차적으로 부드럽게 나타나며, 계속 튀거나 화면을 방해하는 반복 애니메이션은 사용하지 않는다. 장식이 아니라 실제 점검 항목임이 분명해야 한다.

## 시각 디자인

- 히어로 배경색: `#030305`
- 주 텍스트: `#ffffff`
- 보조 텍스트: `#d5d5d5`
- 포인트: `#8a63f8`
- 글래스 배경: `rgba(20, 20, 25, 0.48)`
- 글래스 테두리: `rgba(255, 255, 255, 0.12)`
- 왼쪽 오버레이: 검정에 가까운 색에서 투명으로 이어지는 수평 그라데이션

기존 페이지의 주황색 CTA는 히어로에서 보라색 그라데이션 CTA로 바꾸되, 하단 섹션의 기존 주황색 디자인은 유지한다. 히어로와 다음 섹션 사이에는 갑작스러운 단절을 줄이기 위해 어두운 영역에서 기존 밝은 캔버스로 이어지는 짧은 시각적 전환을 둔다.

## 반응형 동작

- 데스크톱: 카피는 왼쪽, 점검 포인트는 방 내부 오른쪽에 배치한다.
- 태블릿: 제목 크기와 좌우 여백을 줄이고 점검 포인트 라벨을 짧게 유지한다.
- 모바일: 배경 이미지 초점을 창문과 책상이 보이는 중앙으로 이동하고, 카피를 화면 하단에 배치한다. 겹침이 발생하는 점검 포인트는 최대 두 개만 노출한다.
- 모바일 CTA는 한 손으로 누르기 쉬운 전체 폭에 가까운 크기로 확장한다.

## 접근성과 성능

- 배경 이미지는 장식 목적이므로 CSS 배경 또는 빈 대체 텍스트를 사용하고, 핵심 정보는 HTML 텍스트로 제공한다.
- 텍스트와 버튼은 배경의 밝은 영역에서도 WCAG AA 수준의 대비를 확보한다.
- 키보드 포커스 스타일을 유지하고, CTA의 기존 앵커 목적지를 변경하지 않는다.
- 생성 이미지는 WebP로 최적화하며 데스크톱과 모바일에 적절한 크기를 제공한다.
- 외부 영상 자동재생에 의존하지 않아 초기 로딩과 브라우저 정책 문제를 피한다.

## 검증 기준

- 첫 화면만 보고 고시원 계약 전 확인 서비스임을 이해할 수 있다.
- 1440px, 1024px, 768px, 390px 화면에서 제목·CTA·방의 주요 요소가 겹치거나 잘리지 않는다.
- CTA가 `#get-checklist`로 이동하고 기존 신청 폼이 정상 작동한다.
- `prefers-reduced-motion`에서 배경 이동과 진입 애니메이션이 제거된다.
- 자동화 테스트와 정적 검사 모두 통과한다.
- 실제 브라우저에서 데스크톱과 모바일 스크린샷으로 시각적 완성도를 확인한다.
