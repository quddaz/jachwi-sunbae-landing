# 체크리스트 단계 시퀀스 디자인

## 목표

체크리스트 미리보기에서 방 선택 항목과 이사 전 혜택 확인을 한 묶음으로 섞지 않고, 사용자가 실제로 행동하는 순서에 맞춰 두 단계로 보여준다.

## 화면 구조

기존 `놓치기 쉬운 순간마다 한 칸씩 확인하세요` 카드 안을 다음 두 구역으로 나눈다.

1. **방 선택**
   - 로드뷰 주변 업종
   - 창문과 환기
   - 수압과 온수
   - 벽 재질과 방음
   - 계약과 퇴실 조건
2. **이사 전**
   - 내 지역 주거 혜택 확인
   - 청년 월세·이사비·보증료 지원 탐색

두 구역 사이에는 짧은 연결선 또는 화살표를 사용해 `방 선택 → 이사 전` 순서를 명확히 한다. 모바일에서는 위아래로 쌓고, 넓은 화면에서도 읽는 순서는 유지한다.

## 수량과 문구 규칙

- 기존 고시원 점검 항목은 정확히 25개로 유지한다.
- 화면에 보이는 방 선택 미리보기는 현재 5개를 유지한다.
- 주거 혜택은 25개 점검 항목에 포함시키지 않고 별도 추가 정보로 표시한다.
- 기존 혜택 소개 섹션과 이메일의 공식 지원 정보 링크는 변경하지 않는다.
- 미리보기 하단 문구는 방 선택 항목과 혜택 정보의 관계가 오해되지 않도록 조정한다.

## 접근성과 반응형

- 단계 제목은 단순 장식이 아니라 읽을 수 있는 텍스트로 제공한다.
- 체크 항목은 보조기술에서도 순서가 전달되는 목록 구조를 사용한다.
- 모바일 390px 너비에서 가로 스크롤 없이 표시한다.
- 모션은 추가하지 않아 기존 모션 감소 정책에 영향을 주지 않는다.

## 테스트

- 정적 HTML 테스트에서 `방 선택`, `이사 전`, 혜택 관련 문구를 확인한다.
- 방 선택 미리보기 항목이 5개인지 확인한다.
- 전체 이메일 체크리스트가 여전히 25개인지 기존 테스트로 확인한다.
- 전체 Node 테스트와 정적 검사를 실행한다.
- 배포 후 모바일 화면과 단계 순서를 브라우저에서 확인한다.
